## Workflow
- Activate `planning` skill for analysis approach.
- Profile application performance (CPU, memory, I/O).
- Identify slow queries, expensive operations, bottlenecks.
- Analyze resource usage patterns.
- Generate performance report with optimization recommendations.

**IMPORTANT:** Focus on high-impact optimizations first.
**IMPORTANT:** Provide before/after metrics when possible.
